# Bank Management System (C++)

## About the Project
A simple console-based Bank Management System developed using C++.

This project is created without Object-Oriented Programming (OOP) concepts. It uses basic programming concepts such as arrays, loops, conditional statements, and switch cases.

## Features
- Create a new bank account
- Display all accounts
- Deposit money
- Withdraw money
- Check account balance
- Exit the system

## Technologies Used
- C++
- Arrays
- Loops
- Switch Statements
- Conditional Statements

## How to Run
1. Download or clone this repository.
2. Open `main.cpp` in a C++ IDE.
3. Compile and run the program.
